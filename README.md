# pairwise-lag-compensation

高延迟玩家打静止靶，服务器回放里明明命中却判未中，回滚只取了当前 hitbox 没按时间采样；插值位置与快照时间戳不对齐，快速横移时判定盒偏半个身位；客户端预测命中提前上报，服务器把预测当事实；武器射速按客户端帧率算，服务器 tick 下实际更快；后坐力客户端算一套服务器又算一套，弹道分叉；霰弹多 pellet 用不同随机种子，两边命中数不一致；护盾与血量的判定顺序反了，打穿护盾那一下被吞；高速投射物只测端点没做扫掠，穿过薄目标不判中；丢包重传让同一发子弹上报两次，伤害翻倍；回滚窗口开到 300ms，静止靶也能被追着打。gameplay/lag_compensation.py 是核心，tests/test_lag_compensation.py 15个红。要修的是：回滚按时间采样 hitbox；插值对齐快照时间；预测只做表现不上报；射速由服务器 tick 驱动；后坐力服务器权威；pellet 种子由服务器下发；护盾与血量按固定顺序结算；高速弹做扫掠检测；命中带唯一序号去重；回滚窗口按延迟上限收紧。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
